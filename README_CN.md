# 维特根斯坦与大语言模型：从逻辑表征到语言实践

**一个关于语言、规则遵循与大语言模型的跨学科研究项目**

* **研究主题：** 后期维特根斯坦哲学、大语言模型、语言实践与规则遵循
* **项目类型：** 哲学分析与实证研究相结合的研究项目
* **报告版本：** 正式版 1.0
* **在线阅读：** [阅读完整研究报告](https://chironcuiyang-bot.github.io/wittgenstein-llm-practice/#appa)
* **研究语言：** 中文

## 一、项目简介

大语言模型能够生成连贯的文本、解释复杂概念、遵循指令，并在多轮交互中表现出一定程度的上下文适应能力。但这些能力究竟意味着什么？模型是在学习语言的形式规律，还是已经具备了某种更接近人类语言实践的能力？

这一问题不仅涉及机器学习的技术机制，也触及语言哲学中的经典议题：语言的意义从何而来？遵循规则意味着什么？一个系统能够正确使用语言，是否就意味着它理解了语言？

本项目以维特根斯坦后期哲学为主要理论资源，尝试建立哲学分析与大语言模型实证研究之间的联系。研究的重点不是简单地判断模型是否具有理解能力，而是考察：当语言使用发生在持续的情境、社会角色、规范约束、行动后果以及他人反馈之中时，我们应当如何描述和评估模型的行为。

项目希望将一个容易停留在概念争论中的问题，转化为可以进行操作化定义、对照实验和经验检验的研究议程。

## 二、核心研究问题

本项目围绕以下问题展开：

1. **语言意义与使用。** 如果意义不能脱离语言的实际使用来理解，那么仅从文本预测和静态问答表现出发，是否足以描述大语言模型的语言能力？

2. **规则遵循。** 模型能够生成符合规则的答案，是否等同于能够在不同情境下持续、稳定地遵循规则？我们应当如何区分局部正确、模式匹配与情境依赖的规则使用？

3. **语言实践与社会情境。** 角色关系、共同规范、行动后果、他人回应和状态变化，是否会对模型的行为产生可识别的影响？

4. **理论如何接受经验检验。** 能否将语言实践中的关键结构转化为明确的实验变量，并通过基线比较、负向对照和稳健性检验，评估这些结构是否具有独立的解释价值？

这些问题并不预设大语言模型已经具备人类式理解，也不预设语言实践理论必然优于现有的模型解释框架。研究希望让理论主张与实验结果之间建立更清晰、可检验的联系。

## 三、理论框架

本项目主要借鉴维特根斯坦后期哲学中关于语言使用、规则遵循、生活形式与共同实践的讨论。

在这一视角下，语言并不是一组脱离情境而独立存在的符号与映射关系。语言的使用通常嵌入具体活动之中，并受到参与者之间的关系、共同遵循的规范以及实际行动后果的影响。

将这一视角用于分析大语言模型，需要区分两个层次：

* **哲学层面：** 讨论语言意义、规则遵循与实践之间的概念关系，以及这些概念对理解模型行为提出了什么问题。
* **经验层面：** 将相关概念转化为可操作的实验结构，检验不同实践要素对模型行为的影响。

这两个层次相互关联，但不能直接画等号。实验表现可以支持或削弱某些经验性主张，却不能单独解决所有关于意义、理解或心智的哲学问题。

## 四、从理论到实验

研究尝试将一次语言实践中的关键结构组织为一个联合建模框架，并与具有明确模块边界的基线模型进行比较。

重点考察的维度包括：

* 持续的情境与上下文；
* 角色及角色之间的依赖关系；
* 共同遵循的规范；
* 行动及其后果；
* 其他参与者的回应；
* 参与者状态的后续更新。

实验设计强调预先明确结构定义、对照条件和评价指标，而不是仅根据实验结果事后解释理论。

主要方法要求包括：

1. **基线比较：** 将联合建模方案与具有明确模块划分的强基线进行比较。
2. **实验条件匹配：** 尽可能控制参数规模、计算预算、训练步数、交互次数和监督信号等因素，减少替代解释。
3. **独立重复：** 使用独立随机种子开展重复实验，区分随机波动与可重复的效果。
4. **负向对照：** 通过打乱实践结构等控制条件，检验观察到的效果是否确实依赖于所提出的结构。
5. **稳健性检验：** 检查结果是否依赖于特定实验运行、指标选择或单一配置。
6. **统计报告：** 报告效应量、置信区间以及适当的多重比较校正，而不只报告单一的性能数字。

这些设计旨在提高研究结论的可解释性。实验是否足以支持某项主张，仍然取决于具体实施、数据质量和实际结果。

## 五、研究的贡献与边界

本项目希望在三个方面推进讨论。

**第一，将哲学问题转化为更明确的研究问题。**

与其笼统地争论大语言模型是否真正理解语言，不如进一步追问：哪些语言行为依赖于持续情境、社会规范和行动反馈？这些依赖关系能否被独立识别？

**第二，为模型能力评估提供另一种分析视角。**

传统的静态问答和基准测试能够衡量模型在特定任务上的表现，但未必充分覆盖持续交互中的角色变化、规范冲突、行动后果和状态更新。语言实践视角可以帮助识别这些评估维度。

**第三，建立可以被反驳的经验性主张。**

理论框架不应只用于解释成功的案例，也应明确哪些实验结果会削弱其解释力。强基线、负向对照、重复实验和稳健性分析因此是研究设计的重要组成部分。

与此同时，本项目存在明确的边界：

* 实践结构带来的性能提升，不自动意味着模型拥有意识或人类式理解。
* 联合模型优于基线，不自动证明其哲学基础正确；结果也可能受到架构设计、训练策略或其他因素影响。
* 维特根斯坦哲学不能被简单还原为一套机器学习架构，也不应仅凭某一实验结果宣称完成了哲学理论的验证。
* 实验结论应当限定在实际使用的数据、模型、任务和条件之内。

研究的目标是建立更严谨的理论与经验对话，而不是通过技术实验为一个预先确定的哲学结论背书。

## 六、如何阅读本项目

建议从[完整研究报告](https://chironcuiyang-bot.github.io/wittgenstein-llm-practice/#appa)开始。

阅读时可以重点关注三个层面：

1. **概念是否准确：** 对维特根斯坦原著的引用、术语使用和哲学论证是否忠实于相关文本？
2. **操作化是否合理：** 从语言实践概念到实验变量的转换，是否保留了理论所关心的关键区别？
3. **实验能否支持结论：** 对照组是否足够强，实验条件是否匹配，统计分析和负向对照是否足以排除重要的替代解释？

这三个问题分别对应哲学解释、研究设计和经验推断。它们需要相互配合，但不能互相替代。
